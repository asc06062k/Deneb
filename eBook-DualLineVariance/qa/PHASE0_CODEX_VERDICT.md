3. Optional improvements

- ย้าย Workshop dataset และแนวคิด field/type แบบง่ายมาไว้ก่อนบท JSON เต็มรูปแบบ หรือแบ่งบทที่ 3 เป็น “JSON ขั้นพื้นฐาน” และค่อยสอน `transform`, `condition`, `params` ใกล้บทที่ใช้จริง เพื่อลด cognitive load
- เพิ่มบทสั้นหรือ checklist เรื่องการคัดลอกชื่อ field จาก Deneb Data pane เพราะชื่อ measure, ช่องว่าง และ suffix พิเศษของ interaction ทำให้มือใหม่ผิดพลาดง่าย
- เปลี่ยน “แกนเวลาเดียวกัน” เป็น “แกน Category เดียวกัน” เว้นแต่ contract บังคับ Category เป็นวันที่จริง
- ล็อก Deneb major version ก่อนถ่ายภาพและเขียนขั้นตอน เพราะชื่อ/ตำแหน่ง interactivity settings เปลี่ยนตามรุ่น
- เพิ่ม accessibility checks: สี good/bad ที่ไม่พึ่งสีอย่างเดียว, contrast, tooltip/label formatting และชุดสีสำหรับผู้มีภาวะตาบอดสี
- เพิ่ม performance test ตามจำนวน Category และจำนวน layer เพราะ connector, point, label และ tooltip targets เพิ่มจำนวน marks อย่างรวดเร็ว
- ระบุว่า Blank handling ของ eBook เป็น design decision: source ต้นแบบแปลงค่าที่ไม่ใช่ตัวเลขเป็นศูนย์ จึงไม่ควรเรียกว่าเลียนแบบต้นแบบหากเลือกให้เส้นขาดหรือซ่อน Category
- แยก Template “field mapping” ให้สอดคล้องกับรูปแบบ Deneb template จริง ซึ่งเก็บ metadata/placeholders และ interactivity settings ไม่ใช่การแยก field mapping ออกจาก spec แบบอิสระทั้งหมด

4. คำถามที่ต้องรอหลักฐานจาก Phase ถัดไป

1. Vega-Lite spec ที่เลือกสามารถเปลี่ยนสี area ตรงจุดตัดภายในช่วง Category ได้จริงหรือไม่ โดยไม่ทำให้ provenance สำหรับ cross-filter สูญหาย?
2. Mark ในแต่ละ layer—point, connector, area และ label—ตัวใด click แล้ว Deneb resolve กลับไปยัง Category ได้จริง?
3. เมื่อเปิด cross-highlight แล้ว Actual และ Reference ได้ค่า `__highlight`/`__highlightStatus` อย่างไรในแต่ละ interaction และจะกำหนด opacity ระดับ Category จากสอง measure อย่างไร?
4. Edit interactions แบบ Filter และ Highlight ให้ผลต่างกันอย่างไรกับ visual ฉบับจริง?
5. Blank, Reference=0, negative values, duplicate Category และ Category ที่มี Actual/Reference เพียงด้านเดียวควรแสดงผลแบบใด?
6. Category จำนวนมากจะใช้ fit+thin, scroll หรือจำกัดจำนวน และ threshold ที่ยังอ่านได้บน viewport เป้าหมายคือเท่าใด?
7. Template ที่ export/import จาก Deneb รุ่นที่ล็อกไว้รักษา field mapping และ interactivity settings ครบหรือไม่?
8. หลักฐาน Power BI จริงจะจัดส่งในรูป PBIX, ภาพนิ่ง หรือวิดีโอ และใครเป็นผู้ลงนามผลทดสอบแต่ละ test ID?
