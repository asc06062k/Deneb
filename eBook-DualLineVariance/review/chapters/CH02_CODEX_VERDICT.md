## Optional improvements

- `Interactive bar chart` เหมาะกว่า `Simple bar chart` สำหรับ Step 4 เพราะทำให้ผู้อ่านเห็น `Actual__highlight` และโครงสร้าง layered spec ซึ่งปูทางไปเรื่อง interactivity ได้ดี แต่ควรกล่าวชัดว่าเป็น “template ฝึกสำรวจ Editor” ไม่ใช่ spec ของ Dual-Line Variance Chart ในเล่ม
- ทางลัด `Ctrl+Enter` และ `Ctrl+Shift+Enter` ถูกต้องตามเอกสาร Deneb: Apply Changes และ Toggle Auto-Apply ตามลำดับ จึงไม่จำเป็นต้องลดระดับเป็นเพียงข้อสันนิษฐาน แต่ควรคงหมายเหตุว่า “ยังไม่ได้ทดสอบบนเครื่องที่จับภาพ” หากต้องการแยกหลักฐานเอกสารออกจากหลักฐานภาคสนาม [Deneb Keyboard Shortcuts](https://deneb.guide/docs/keyboard)

- ใช้คำว่า “แท็บ” กับ Specification/Config/Project setup และ “pane” กับ Preview/Debug pane ให้สม่ำเสมอทั้งบท
- ชื่อไฟล์ภาพทั้ง 18 ภาพเป็นไปตามรูปแบบ `CH02-Syy-*` และเลขภาพ 2-1 ถึง 2-18 เรียงและอ้างอิงตรงกับเนื้อหา

## คำถามที่ต้องรอหลักฐานจากผู้ใช้

1. หลังคลิกไอคอนรูปถุงบนการ์ด Deneb ขั้นตอนจริงแสดง dialog/ข้อความอะไร และต้องกด Add หรือยืนยันซ้ำหรือไม่ ควรทดสอบหรือจับภาพอย่างน้อยหนึ่งครั้งก่อนสรุป flow การติดตั้ง
2. ใน Power BI Desktop รุ่นที่ใช้ เมื่อเปิดเมนูของ `Actual` ใน Values ตัวเลือกชื่อ **Don't summarize** ปรากฏจริงหรือไม่ และค่าเริ่มต้นหลังลาก Whole number ลง Deneb เป็นอะไร
3. หลังเลือก **Convert my spec to Vega** มี dialog ยืนยันหรือไม่, Undo ใช้ได้หรือไม่ และสามารถสลับ provider/สร้าง Vega-Lite spec ใหม่ใน Visual เดิมได้อย่างไร จุดนี้ต้องทดสอบก่อนใช้คำอธิบายพฤติกรรมหลังการแปลง
4. ควรทดสอบแบบฝึกหัด `Simple bar chart` หนึ่งรอบเพื่อบันทึก placeholder mapping และผลลัพธ์ที่คาดหวัง โดยเฉพาะวิธีกลับมาใช้ Interactive template โดยไม่ทำลายงานของ Step 5
